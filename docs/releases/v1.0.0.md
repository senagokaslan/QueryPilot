# QueryPilot v1.0.0

Tarih: 25 Ağustos 2026

## Sürüm kapsamı

Bu sürüm; PostgreSQL tabanlı iş verisi, read/write API'leri, beş deterministik analytics akışı, Gemini destekli doğal dil sorgulama ve React frontend içeren ilk doğrulanmış yerel sürümdür.

Cloud deployment kullanıcı kararıyla yapılmadı. Render ve Neon üzerinde çalışan QueryPilot kaynağı yoktur. Aşağıdaki production kontrolleri yerel PostgreSQL'e karşı `ASPNETCORE_ENVIRONMENT=Production` ile gerçekleştirilmiştir; sonuçlar canlı bir cloud ortamı bulunduğu anlamına gelmez.
